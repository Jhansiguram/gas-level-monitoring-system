# Gas Level Monitoring System

## Project Overview
The Gas Level Monitoring System is an IoT-based project designed to detect gas leakage and alert users when the gas concentration exceeds a predefined threshold.

## Objectives
- Detect gas leakage using an MQ-2 gas sensor.
- Monitor gas levels.
- Display readings using an LCD.
- Alert users through LEDs and a buzzer.
- Improve safety through gas leakage detection.

## Hardware Components
- ESP8266 NodeMCU
- MQ-2 Gas Sensor
- LCD Display with I2C
- Two LEDs
- 5V Buzzer
- Resistors
- Breadboard
- Jumper Wires

## Working Principle
The MQ-2 sensor detects gas concentration and sends readings to the ESP8266 NodeMCU. The system monitors the readings and activates visual and audio alerts when the gas level crosses the configured threshold.
